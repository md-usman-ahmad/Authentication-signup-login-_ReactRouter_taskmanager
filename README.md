# 🚀 Task & Project Manager — MERN Stack (React Router)

Hi 👋 I'm **Usman Ahmad**, and I built this **full-stack Task & Project Management App** to sharpen my backend architecture, React Router logic, and secure authentication skills.
This project shows how a real-world task manager works — with user auth, project creation, and task tracking — all connected end-to-end through REST APIs.
---

## 🧠 About the Project

This is a **complete MERN stack web app** where users can:
- 🔐 **Sign up & log in securely** (JWT + bcrypt password hashing)
- 📁 **Create, update, or delete projects**
- ✅ **Add tasks inside projects**
- 🧭 **Access only their own data** (protected routes)
- 💾 **Store data persistently in MySQL**

I built it to understand **frontend-backend communication**, proper **API structuring**, and **state management in React**.

---

## ⚙️ Tech Stack

**Frontend:** React, React Router, Tailwind CSS  
**Backend:** Node.js, Express.js, MySQL  
**Auth:** JWT, bcrypt  
**Other Tools:** Axios, dotenv, REST APIs  

---

## ✨ Key Features

- Clean, responsive **React UI**  
- **JWT Authentication** for secure sessions  
- **Protected Routes** and middleware for validation  
- **Modular APIs** for projects and tasks  
- **Full CRUD operations** on both frontend & backend  
- **Scalable DB design** with foreign key relations
